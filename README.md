# gepiras
Telepíthető szoftver gépírás gyakorlásra/tesztelésre, saját kezelésben lévő google sheettel (feladatbank és eredménygyűjtő) kötve - magánhasználatra. Csak saját eszközökön, és magam számára fejlesztve/tesztelve. Mindenki saját felelősségére használhatja (amíg múködik, de erre sem vállalok garanciát).
